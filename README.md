# Power Up 2 — Checkpoint 1

Standalone Checkpoint 1 for Units 1–3: https://itstxaviers-svg.github.io/PU2checkp.1/

No account or cloud connection is used. The checkpoint asks all 134 words from Units 1–3 in one battle. Progress is saved after each completed question in that browser's local storage; students copy or download the report and send it to their teacher. Clearing site data or changing devices removes local progress. Earlier 45-question attempts remain in history but do not count as a full-checkpoint pass.

The source is maintained in [Powerup2-2026](https://github.com/itstxaviers-svg/Powerup2-2026), at commit `fefbab2`. This repository contains the built static site for GitHub Pages. To update it, build the source with `VITE_BASE_PATH=/PU2checkp.1/ npm run build:checkpoint`, then replace this site's `index.html`, JS/CSS, audio, checkpoint pictures, enemy images and arena image with the new build output.
